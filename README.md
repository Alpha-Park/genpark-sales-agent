# genpark-sales-agent

Autonomous outbound B2B sales development representative.

Stop paying hefty enterprise SaaS fees for automated workflows. This is a terminal-native, open-source alternative to **anlah AI: CanSell**.

A Python-based CLI agent that ingests a lead list, generates personalized cold emails, tracks responses, and automatically queues follow-ups using a local SQLite database and your own SMTP server. Zero per-seat SaaS fees.

## Usage
```bash
openclaw use genpark-sales-agent
```
